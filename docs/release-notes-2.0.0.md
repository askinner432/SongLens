# SongLens 2.0.0

SongLens 2.0 adds a broader set of tools for organizing, searching, comparing, and sharing Studio One projects.

## SongLens View

- Added saved grid views that remember visible columns, column order and widths, sort levels, and active searches. Saved views can optionally include the active date filter.
- Added multi-rule Advanced Search with saved searches and sorting across up to four fields.
- Added quick date filters for song age and Created or Modified date ranges.
- Added editable Status and Genre values and per-song star ratings, stored separately from Studio One project files.
- Added Statistics for the current view and comparisons between an individual song and the full catalog.
- Added snapshot reports for a selected song or multiple results, with list and detailed report formats.

## Project Details And Audio

- Expanded mixer inspection with routing, inserts, sends, VCAs, channel state, and console ordering.
- Added mixdown indicators and playback options, including custom audio player support.
- Added song renaming and improved handling of mixdowns whose filenames no longer match the song name.
- Added font and visible-tab preferences, plus additional interface customization.

## Search, History, And Exports

- Expanded searchable metadata to include track names, instrument names, and track notes.
- Improved History cleanup with explicit deletion selection, a review step, and configurable retention.
- Added CSV and Excel workbook exports with selectable fields and mixer details.
- Updated the user guide and in-app help.
